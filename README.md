# larex-action-sbb

[LAREX](https://github.com/OCR4all/LAREX/) action for [sbbbin](https://github.com/jahtz/sbbbin) image binarization.

## Action Definition

See `action.yml`

### Endpoint definition

```yaml
endpoint:
  url: http://kraken.example.com/dispatch
  healthUrl: http://kraken.example.com/health
  parameterValuesUrl: http://kraken.example.com/parameter-values
  timeoutSeconds: 30
  auth:
    type: hmac
    secretRef: sbbbin-v1
```

Create the endpoint secret in LAREX under `Admin / Actions / Endpoint Secrets` and copy the one-time revealed value into the processor environment as `LAREX_DISPATCH_HMAC_SECRET`.

### Model selection
```yaml
parameters:
  Model:
    type: string
    description: SBB Binarization model
    default: <sbb-default-model>
    allowedValues:
      provider: models
```

## Configuration

### Action Configuration

| **Variable**                     | **Default**            | **Description**                                                                                                           |
|----------------------------------|------------------------|---------------------------------------------------------------------------------------------------------------------------|
| `LAREX_PROCESSOR_ID`             | `sbb-binarization`     | Processor id expected in dispatch headers.                                                                                |
| `LAREX_DISPATCH_HMAC_SECRET`     | required               | Shared dispatch HMAC secret generated by LAREX.                                                                           |
| `LAREX_ALLOWED_CALLBACK_ORIGINS` | required               | comma-separated LAREX callback origins accepted by the SDK.                                                               |
| `LAREX_ACTION_ROUTE_PREFIXES`    | `["/sbb-binarizaton"]` | Optional comma-separated route prefixes, for example `/kraken`, that also expose prefixed `/dispatch`, and health routes. |
| `LAREX_ACTION_DEBUG`             | `false`                | Enable action worker logging                                                                                              |
| `LAREX_SDK_TRANSPORT_LOGGING`    | `false`                | Set to true to log SDK pulls, heartbeats, downloads, uploads, retries, and failures locally.                              |
| `BIND_ADDRESS`                   | `0.0.0.0`              | Docker bind address                                                                                                       |
| `PORT`                           | required               | Docker exposed port                                                                                                       |

`/health` is a liveness endpoint. 
`/preflight` is the authenticated LAREX configuration check; it verifies the HMAC secret and processor id and reports protocol and result capabilities. 
The authenticated `/parameter-values` route discovers valid segmentation models from Kraken's normal model directories and KRAKEN_MODEL_DIRECTORY. 
/ready returns 503 while all configured run slots are occupied, allowing an orchestrator to stop routing additional work to a busy instance.

### SBB Configuration

| **Variable**              | **Default**    | **Description**                                                                                                     |
|---------------------------|----------------|---------------------------------------------------------------------------------------------------------------------|
| `SBB_SUFFIX`              | `.sbb.bin.png` | Result file suffix/extension.                                                                                       |
| `SBB_DEVICE`              | `cuda  `       | Computation device. Options: `cpu`, `cuda`.                                                                         |
| `SBB_MODEL_DIR`           | required       | Path to pytorch model directory. Should contain one or multiple `.pth` files.                                       |
| `SBB_MAX_CONCURRENT_RUNS` | `1`            | Maximum sbbbin runs admitted concurrently in one processor instance. Increase only after measuring host/GPU memory. |
